# Ask Questions If Underspecified

Resolve facts from the conversation, relevant files, and established conventions first. Ask only when plausible answers would materially change scope, correctness, safety, authority, or the intended outcome.

Ask the smallest useful set, usually one question. Explain the consequence and give a recommendation when the evidence supports one. Use an available question tool within its actual limits; otherwise ask concisely in chat. Do not impose a questionnaire or repeat settled decisions.

Continue authorized work that does not depend on the answer. Wait before taking dependent actions; silence is not an answer or approval. Use established defaults for low-impact choices and state consequential assumptions briefly.

When the user explicitly asks for an interview or to stress-test an idea, use the sibling [Grilling skill](../grilling/SKILL.md). Routine implementation ambiguity does not call for an interview.
